# Car Dealership Application

**Repository Name:** `xrwvm-fullstack_developer_capstone`

**Project Name:** IBM Full Stack Developer Capstone — Car Dealership Application

## Project Overview

This full-stack web application allows users to browse car dealerships, view dealer details, register and log in, and submit dealership reviews.

The application uses a React frontend, Django backend, Node.js and Express dealership API, MongoDB Atlas database, and a sentiment analysis microservice.

## Technologies Used

- React and JavaScript
- Python and Django
- Node.js and Express
- MongoDB Atlas
- Flask and NLTK for sentiment analysis
- GitHub Actions for CI
- IBM Cloud Code Engine and IBM Container Registry for deployment
